# React Starter

A React app powered by Vite with React Router.

## Getting started

```sh
npm install
npm run dev
```

## Available routes

- `/` — Home
- `/about` — About

Add routes in `src/App.jsx` and place the router-aware app inside `BrowserRouter` in `src/main.jsx`.

## Checks

```sh
npm run lint
npm run build
```
